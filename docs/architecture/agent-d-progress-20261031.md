## A–C 연결

상담용 A 노드가 실제 DB의 `eligibility_rule_sets`, `eligibility_requirements`를 같은 읽기 전용 스냅샷에서 조회합니다. 소문자 대상 유형을 DB의 대문자 유형으로 변환하고, 동일 릴리스의 `definition`을 기존 평가기에 전달합니다. 대상이 잘못 연결되면 거부하고, DB 오류를 규칙 없음으로 숨기지 않습니다.

- 자동 테스트 9개 통과
- 실제 DB 읽기 전용 검증: 규칙 집합 52개, 요건별 결과 591개, 빈 대상 0개
- 기관 심사, 시점 재확인, 근거 범위 미완성은 기존대로 추가 확인 상태를 유지

## D 구현

### 프로필

- 저장 버튼과 상담 버튼을 연결했습니다. 동일 탭의 세션 저장소에 프로필과 입력 폼을 저장·복원합니다.
- 생년월일을 직접 입력받습니다. 만 나이에서 생년월일을 추측하지 않습니다.
- 국적은 한국어 주요 국가명 또는 2자리 코드, 복수 국적은 쉼표·슬래시 구분을 지원합니다.
- 국가·목적을 여러 개 선택하면 특정 하나를 임의로 확정하지 않습니다. 복수 선택 내용은 자유 텍스트 문맥으로 전달합니다.
- 학력·경력·거주·언어 등은 현행 C 계약이 허용하는 `purpose` 문맥에 보존합니다. 이 정보를 개별 자격 규칙의 참/거짓 필드로 자동 변환하지 않습니다.
- 기존 상담이 있으면 프론트 서버 PATCH를 통해 현행 상담 API의 프로필 재검토를 호출합니다. 결과·체크리스트를 교체하고 비교 선택을 초기화합니다.
- 새 상담은 저장된 프로필을 기존 프로필 PATCH 계약으로 먼저 적용한 뒤 사용자 질문을 전송합니다. 현재 C 계약을 변경하지 않으므로 프로필이 있는 첫 요청은 그래프를 두 번 실행할 수 있습니다.

### 상담·비교·준비

- 상담 세션 ID, 메시지, 비교 선택을 같은 탭 내에서 복원합니다.
- 새 상담을 시작하면 이전 요청의 늦은 응답이 새 화면을 덮어쓰지 않도록 요청 버전을 확인합니다.
- 상담에서 선택한 실제 프로그램 ID를 독립 비교 화면으로 전달합니다. 고정 일본·호주 예시와 임의의 비용·기간 표시는 제거했습니다.
- 비교 화면은 반환된 국가·유형·설명·ID를 표시합니다. 현재 비교 선택의 출발점은 상담 결과입니다. 프로그램 목록 페이지의 자체 비교와는 아직 공통화하지 않았습니다.
- 준비 항목은 마지막 상담·재검토 결과를 사용합니다. 완료 표시는 사용자 준비 진행 상태이며 자격 승인과 별개입니다.
- 프론트 `dev`, `build`는 이 환경에서 검증한 webpack 모드를 사용합니다.
