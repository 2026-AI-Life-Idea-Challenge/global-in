# 프로그램 통합 복구와 플랜 화면

브랜치: MJfront. 기존 통합 구현 `80eb98f`, `0008024`를 확인하고 DB ID 기반 화면에 연결했다. 정책 DB·임베딩·승인 상태는 수정하지 않는다.

## 프로그램 표시

- 417·462는 목록에서 각각 카드 하나만 표시한다. 상세 화면의 첫 신청·2차·3차 버튼은 실제 단계 ID로 이동하고 해당 단계의 원문 데이터를 조회한다. 개별 단계 ID는 규칙 검토·플랜에서 보존한다.
- WEST 본 프로그램과 `KR_US_WEST` 사업은 목록에서 WEST 프로그램 하나로 보인다. 상세 화면에는 프로그램 소개와 모집·지원 안내 링크를 구분하며 두 대상의 데이터셋 본문을 연결한다. WEST 어학연수비 대출은 별도 지원제도다.
- 기존 WEST 링크는 국립국제교육원의 실제 소개 페이지와 2026년 하반기 모집 공고를 확인했다. 공고 링크 제공은 현재 접수 중이라는 의미가 아니다.
- 실제 DB의 52개 항목 모두에 한국어 표시명과 서로 다른 경로 소개를 추가했다. 공식 원문명과 원본 ID를 보존한다. 소개는 경로의 성격만 설명하며 수치·자격·최신성·승인을 확정하지 않는다.
- `공식 자료를 바탕으로 제공되는 프로그램 정보입니다` 같은 동일 소개를 제거했다. 확인일이 없으면 임의 날짜 대신 연결된 출처 수와 확인할 정보 영역을 표시한다.

## 플랜

- 사용자 첨부 화면을 기준으로 프로그램 선택 카드·개별 진행률·선택 프로그램 설명·미확인 조건·단계별 할 일·추가/수정/삭제·상담 이동을 구성했다. 현재 색상 변수·폰트·Sidebar·Header를 사용하고 전역 CSS는 변경하지 않았다.
- 준비 항목은 신청 전 준비와 신청 준비로 구분한다. 신청 방법·입력 정보·비용 확인은 준비 제안으로 표시하고 공식 필수 서류라고 주장하지 않는다.
- 실제 규칙과 프로필에 따른 확인 행동에는 원문·판정 근거를 펼쳐 볼 수 있다. 길고 반복되는 규정 전문을 할 일 제목에 붙이지 않는다. 생성 항목은 AI 추천으로 구분하고 수동 항목은 내가 추가로 표시한다.
- 기존 자동 생성 항목은 version 3으로 갱신한다. 수동 항목을 유지하며, 마지막 항목이나 프로그램을 삭제하면 빈 화면으로 돌아간다. 로컬 저장 방식을 유지한다.
- 실제 DB의 호주 186 노동협약 경로에서 준비 행동 5개와 신청 준비 제안 3개, 총 8개가 생성되는 것을 확인했다.

## 상담

- 상담 아래의 근거 상태·원문 인용·대량 출처·준비 항목 개수 UI를 제거했다. 근거 데이터 자체를 삭제하지 않는다.
- 프로그램과 지원제도 후보는 같은 카드로 연결하고 화면에는 최대 3개를 표시한다. 공식 페이지와 플랜 추가를 제공하며 자세히 보기는 제공하지 않는다.
- 플랜에서 특정 할 일을 질문하면 해당 질문을 상담 입력으로 전달한다. 실제 `/api/chat` → 백엔드 상담 API 연결을 유지한다.
