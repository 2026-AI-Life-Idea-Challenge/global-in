# PR #29 통합 기준과 검증

사용자 지시에 따라 MJfront의 프로그램·지원제도 찾기 목록, 상세 디자인, 최근 설명 정리를 유지하고 나머지 기능을 통합했다.

- 기준 MJfront: `18f5e7d`
- 통합 대상 koFrontTest: `356469e`
- 작업 브랜치: MJfront. 새 브랜치를 만들지 않는다.

## 현재 버전 그대로 보존

- `frontend/app/programs/` 전체
- `frontend/components/ProgramRequirements.tsx`
- `frontend/components/ProgramActions.tsx`
- `frontend/app/globals.css`

최초 통합 시 위 경로는 기준 커밋과 차이가 없었다. 이후 사용자 정정에 따라 파일 전체 보존 대신 디자인·구성 보존으로 기준을 좁히고, 목록의 비교표 접기·펼치기, 개별 비교 해제, 비교표 바로 이동 기능을 복원했다. 기존 비교표 제목·열 제목 영역에 필요한 조작만 연결했다. #29의 필터 디자인·고정 요약 바·목록 비교표 스타일·상세 간격·요건 카드 CSS 변경은 채택하지 않았다. 호주 단계 통합, WEST 통합, 한글 소개, 주제별 설명과 원문 펼침을 유지한다.

## 통합한 기능

- 플랜 완료율·남은 할 일·상태 필터, 편집 메뉴, 설명·메모 입력, 삭제 취소와 기존 완료 상태·순서 복구
- 할 일이 0개인 프로그램은 삭제 취소와 추가를 위해 유지한다. 프로그램 제거 또는 플랜 전체 삭제 시 기존 빈 화면으로 돌아간다.
- 채팅 진입·대화별 세션/프로필 분리 유지
- 상담 인증·세션 만료·혼잡·저장소·답변 생성 오류 안내 구분
- 로컬 임베딩 모델을 사용할 수 없으면 키워드 검색으로 대체. DB·실제 추론 오류는 무조건 숨기지 않는다.
- #29에 포함된 홈·상담 국기 컴포넌트 및 관련 문서 변경 유지. 보호한 찾기 화면은 기존 국기 구현을 그대로 사용한다.
- 기능 차이 없는 줄바꿈 변경 135개 파일은 제외하고 실제 변경 파일도 기존 줄바꿈 형식을 유지한다.

## 검증

- Python 286개 + 223 subtests 통과(기존 경고 4개)
- webpack 프로덕션 빌드·TypeScript 통과
- API·SSR 17개 통과
- Chromium 기존/통합 흐름 45개 + 채팅 분리 18개 통과
- 플랜 완료/미완료 필터 및 삭제 취소 후 완료 상태 복구 추가 검사
- 브라우저 검증은 합성 API를 사용하며 유료 LLM·DB 쓰기·배포는 실행하지 않음

충돌 해결은 최신 MJfront 검사를 유지하고 새로운 편집 메뉴·오류 안내에 맞춰 조작을 조정했다.
