# 상담 범위·비교·개인화 플랜 보완

후속 수정: 자격 규정 전문을 제목에 붙이던 방식을 제거했다. 한국어 행동 항목으로 묶고 원문·판정·이유는 펼쳐 보는 근거에 보존한다. 상담의 원문 확인 항목을 생성 결과에 다시 추가하지 않는다. 기존 자동 생성 항목도 task_version=2 형식으로 갱신하며, 사용자 수동 추가 항목은 유지한다. 실제 DB의 호주 186 Labour Agreement 경로에서 긴 규칙 10개가 행동 항목 5개로 묶이는 것을 확인했다.

MJfront에서 작업. CSS 파일과 기존 페이지 배치를 변경하지 않았다. 비교 메뉴와 준비 항목 재검토 버튼은 기존 컴포넌트에 기능으로 추가했다.

## 개인별 준비 항목

- `/consult/preparation`은 선택한 프로그램과 검증된 프로필을 기존 A 규칙 평가기에 전달한다. LLM을 호출하지 않으며 DB는 읽기 전용이다.
- 충족 조건은 증빙 준비, 미충족은 부족 조건 보완, 미확인은 추가 확인 항목으로 만든다. 개인 심사 결과나 필수 서류·마감일을 만들어내지 않는다.
- 규칙이 없는 대상은 저장된 원문 항목을 제공한다. 데이터도 없으면 생성 실패를 표시한다.
- 목록·상담의 플랜 추가는 같은 생성 API를 사용한다. 기존 단일 `source:` 항목은 플랜 진입 시 갱신한다. 최신 프로필로 재검토하는 버튼도 제공한다.
- 완료 상태는 같은 ID와 설명에 한해 유지하고 수동 추가 항목을 보존한다. 삭제한 플랜은 자동 갱신의 늦은 응답으로 되살리지 않는다.
- 브라우저 localStorage 저장 방식은 유지한다. 서버에 사용자 준비 상태를 영구 저장하는 구현은 포함하지 않는다.

## 상담 범위와 비교

- 명시한 국가·워홀 주제를 우선 적용하고, 전체 안내 후속 질문에서는 이전 범위를 유지한다. 모델의 null 추출만으로 기존 프로필을 지우지 않는다.
- 일반 전체 안내는 개인 자격 검토와 단계 질문을 거치지 않고 공식 정보 검색으로 진행한다. 프로그램 전용 질문에는 지원제도를 함께 반환하지 않는다.
- 사용자 답변은 검증된 claim을 원문 그대로 표시하고 내부 전체 후보 누락 목록을 출력하지 않는다. 부족 근거는 계속 표시한다. DB 승인 상태는 변경하지 않는다.
- 사용자용 RAG 모드는 실제 프로필 국적을 보존하며 미확인 국적을 한국으로 가정하지 않는다.
- 상담 비교 항목도 목록과 같은 카탈로그 메타데이터로 보완한다. 출처 없는 상담 카드가 이미 확보된 공식 링크를 덮어쓰지 않는다.

## 확인 결과

- Python 275개 + 223 subtests 통과(기존 경고 4개).
- 실제 DB: `AU:subclass_186_labour_agreement`에 국적·생년월일·거주지를 적용하면 준비 항목 10개, 출처 있는 항목 10개를 반환했다. 추가 개인 정보가 필요한 항목은 미확인 상태를 유지했다.
- 프론트 TypeScript·webpack 빌드, 변경 모듈 lint 통과(기존 Sidebar img 경고 1개). API·SSR 13개 및 실제 Chromium 흐름 29개 통과. 브라우저 검증은 합성 API를 사용하며 공식 출처 링크·체크리스트 CRUD를 포함한다.
- 후속 작업에서 실제 연결된 모델로 호주 워홀 전체 안내 1회를 검증했다. 국적·준비 자금·2차/3차 지정근로 등 근거 있는 claim 8개를 반환했다. 모든 개요 주제가 충분히 검색·설명된 상태는 아니며 전체 국가·다중 턴 의미 정확성을 보장하지 않는다.

DB 변경·임베딩 생성 없음. 루트 package-lock.json 삭제는 기존 변경으로 커밋에서 제외한다.


## 상담 화면 후속 요구 반영

- AI 답변을 중심으로 표시하고 추천 카드는 최대 3개로 제한한다. 인용 근거가 있는 후보를 우선 표시하고, 개요 답변에서는 근거가 연결된 후보만 반환한다. 전체 후보의 최적 순위 판정은 아니다.
- 카드 설명은 첫 번째 근거 기반 claim을 사용한다. 상담 카드에는 공식 페이지·플랜 추가를 제공하고 자세히 보기를 제공하지 않는다. 프로그램 찾기의 자세히 보기는 유지한다.
- 데스크톱 사이드바와 모바일 Header의 별도 비교 메뉴, 상담의 비교 화면 열기 링크를 제거한다. 기존 화면 내 선택 비교 기능과 /compare 경로는 유지한다.
- 공식 페이지는 카탈로그 출처로 보충한다. 추가 근거 확인 문구는 항목명으로 중복 제거한다.
- 개요 검색을 국적/연령·체류/근로/학업·재정/건강/품행·신청 절차·연장·비용·모집 시점의 7개 주제로 확대한다.
- 최신 검증: Python 276개 + 223 subtests, webpack 빌드, 변경 파일 lint 에러 0개(기존 img 경고 2개).
