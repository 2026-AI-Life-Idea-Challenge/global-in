# MJfront 기능 연결 — 2026-10-31

## 변경 범위

- 로고 좌표 수정은 `79ae4ae`에 별도 커밋했다.
- 기존 디자인·CSS 파일·기존 카드/섹션 배치를 교체하지 않았다. 기존 버튼 영역에 필요한 동작을 추가했다. 기존 화면/컴포넌트의 인라인 스타일 169개가 유지되는 것을 대조했다.
- 상담 후보의 임의 3개 제한을 제거했다. 상담 프로그램 및 지원제도에서 비교·플랜 추가·공식 ID 기반 상세 이동을 연결했다.
- 목록의 기존 버튼 영역에 플랜 추가를 연결했다. 비교 내용은 상담/목록/비교 화면에서 국가·자료 유형·목적·기관·설명·검토 상태·모집 상태·확인일 기준으로 공통화했다. 확인되지 않은 조건이나 비용·기간은 생성하지 않는다.

## 플랜 저장 규칙

- `localStorage`의 `global-in-plans-v1`에 프로그램/지원제도별 준비 항목을 저장한다. 동일 프로그램을 다시 추가해도 같은 항목은 중복 생성하지 않으며 완료 상태를 초기화하지 않는다.
- 기존 상담 결과의 준비 항목은 새 저장소가 없을 때만 가져온다. 삭제 후 저장한 빈 목록은 의도적인 삭제이므로 상담 결과로 다시 채우지 않는다.
- 항목 추가·이름/설명 수정·삭제·완료 체크·전체 삭제와 프로그램별 완료 개수를 제공한다.
- 마지막 항목 또는 전체 플랜을 삭제하면 기존 빈 화면으로 돌아간다. 새로고침 후에도 삭제/수정/완료 상태를 유지한다.
- 상담에서 만든 항목이 없으면 공식 요건/절차 확인 항목을 추가한다. 이를 필수 서류나 자격 승인으로 표현하지 않는다.
- 현재 저장 범위는 해당 브라우저다. 서버 DB 영구 저장·계정 간 공유·기기 간 동기화는 구현 범위에 포함하지 않는다.

## 프로필 반영

- 상담 API의 구조화된 프로필을 기존 폼/프로필과 병합한다. 기존 부가 정보와 복수 국가 선택을 근거 없이 지우지 않는다.
- 생년월일·국적·거주 국가·목적지·목적·학력·학적·전공·경력·언어·자격 정보를 반영한다. 생년월일을 나이에서 추측하지 않는다.
- 현재 프로필 폼에서 보내는 거주국이 API에서 거부되는 문제를 수정하고 부가 정보의 입력 계약을 연결했다.
- 자유 텍스트 학력·언어·경력은 대화 문맥이며, A 평가기의 기계 판정용 사실로 전달하지 않는다.
