## 실제 수정

미국 원문 추출기 `scripts/ingest/usa/shared/evidence/build_usa_program_source_content.py`에서 일반 텍스트와 HTML 주석·처리 지시문을 구분하고 공유 UI를 제외했다. `Comment`, `ProcessingInstruction`이 `NavigableString`을 상속한다는 점을 놓친 것이 기존 오염의 원인이었다.

`scripts/ingest/common/legal_review/repair_evidence_quotes.py`는 기존 생성기의 최상위 쓰기 작업을 실행하지 않고 순수 추출 함수만 읽는다. 원본 HTML 해시, 섹션 번호·제목, 수정 인용문의 HTML 추출 텍스트 내 존재 여부를 검증한 뒤 `quote_corrections_20261028.json`을 생성한다. 기존 데이터의 기대 해시와 의존 관계를 임의로 바꾸지 않도록 기존 스냅샷·가공 근거 JSON·DB를 덮어쓰지 않는다. 해당 파일은 적용 가능한 수정 레코드와 전후 비교를 담은 별도 검토 산출물이다.
