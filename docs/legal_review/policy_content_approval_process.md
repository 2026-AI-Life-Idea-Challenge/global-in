# 정책 문구 법률 검토·승인 기준

## 승인 시점

모든 국가의 자료 수집이 끝날 때까지 기다리지 않는다. **정책별 문구·버전을 고정하고 아래 검토를 통과한 시점에 해당 범위의 검증 완료를 기록한다.** 다른 정책의 판례·모집 공고·개별 노동협약 확인이 남았다는 이유로 무관한 정책까지 일괄 보류하지 않는다.

1. 주장과 적용 범위, 대상 기간을 명시한다.
2. 공식 원문·조문과 출처 URL·버전·해시를 연결한다.
3. 시행일·신청일·초청일·지명일 중 해당 판단 시점을 확인한다.
4. 예외·면제·경과조치를 확인하고 원문과 해석을 구분한다.
5. 해당 문구에 영향을 주는 미해소 쟁점이 없는지 확인한다.
6. 검토자, 판정, 승인한 문구의 해시와 재검토 조건을 남긴다.

이번에 기록한 승인자는 Codex다. 이는 **프로젝트의 범위가 명시된 정책 문구 검증**이며, 독립 법률전문가의 서명·법률의견서 또는 정부의 비자 승인과 동일하지 않다. 변호사 서명이 필요한 별도 검토를 이 기록으로 대체하지 않는다.

## 개인 심사와 분리

“신청 당시 나이 기준은 무엇인가”, “노동협약에서 정한 영어 기준을 따른다” 같은 일반 조건의 문구를 검증하기 위해 실제 신청자의 개인정보나 모든 고용주의 협약 원문이 필요한 것은 아니다. 특정인의 나이 충족 여부, 특정 협약의 양허 수치, 범죄·취소 이력의 실제 적용을 결정할 때는 그 자료가 필요하다.

직종 목록·주정부 페이지 색인, 자동 검사 통과, 보류 ID가 없는 상태만으로 승인하지 않는다. 문구 자체의 실질 대조가 필요하다. 한 항목의 승인은 나머지 비자 요건 충족을 뜻하지 않는다.

## 승인 대상과 집계

승인 원장은 `data/processed/legal_review/policy_content_approval_registry_20261028.json`이다. 승인된 문구는 별도 버전과 해시를 가진다. 원본 스냅샷과 기존 DB의 승인 플래그는 바꾸지 않는다. 전체 590개 정책 중 승인 버전이 있는 정책 ID를 중복 없이 세며, 승인 범위를 함께 표시한다.

2026-10-28 첫 판정은 417·462 연령 조건 6개였으며 별도 `australia_age_content_approvals_20261028.json`에 보존했다. 이후 590개를 한 번에 판정한 최신 결과는 **558/590 (94.58%) 범위 한정 문구 승인, 과거 공고 제외 20개, 미승인 정책 12개이며 추가 승인 2개의 미해결 범위도 별도 보존**다. 호주는 **219/223 (98.21%)**다. 국가별 집계와 항목별 사유는 [일괄 판정 보고서](global_policy_wording_decisions_20261028.md)에 있다. 서비스 사용 승인과 임베딩 실행은 각각 **0건**이다. 원문을 보존하는 DB 별도 검토 버전 저장은 **590건**이며 [반영 보고서](final_policy_batch_and_db_update_20261028.md)에 기록했다. 독립 변호사 서명도 **0건**이다.

원문 서버의 HTML/PDF를 저장한 경우에는 그 원본 파일의 해시를 연결한다. 자동 다운로드가 실패했지만 공식 페이지를 웹 도구로 읽은 경우에는 도구 결과를 별도 파일에 보존하고 `capture_kind=web_tool_rendered_text_not_origin_html_bytes`와 해시 범위를 표시한다. 이 해시는 원본 HTML 바이트 일치의 증명이 아니다. 실패한 수집 결과는 성공으로 덮어쓰지 않는다.

캐나다처럼 원본 문구가 NULL인 경우에는 빈 문구를 승인하지 않고 별도 새 문구·버전·해시와 `original_policy_text_was_null`을 기록한다. 일본 제출자료 승인은 지정 표·신청 종류·분류·국적 열·조건부 행 범위의 승인이다. 체류자격의 실체 요건 전체나 자동 국적 분류의 승인으로 확대하지 않는다.

다음 단계는 승인된 버전의 데이터 반영 및 서비스 사용 범위를 별도로 결정하는 것이다. 사용자별 자격 판정 승인은 별도이며, 데이터 문구 검증 결과로 자동 활성화하지 않는다. 새 법령·공고·출처·문구 변경 또는 다른 신청 기간을 적용하면 재검토한다.

## 실행

```powershell
.venv\Scripts\python.exe scripts/ingest/australia/finalize_age_policy_review.py
.venv\Scripts\python.exe scripts/ingest/australia/finalize_age_policy_review.py --check

.venv\Scripts\python.exe scripts/evaluate/legal_review/audit_policy_content_approvals.py
```

연령 생성기는 여섯 항목의 역사적 별도 결과만 재현하고 전체 승인 원장을 덮어쓰지 않는다. 전체 생성기는 고정한 입력 스냅샷에 대한 이번 실질 검토의 판정·대체 문구를 재현하며 새 정책을 분류하여 자동 승인하는 도구가 아니다. 입력 해시가 바뀌면 중단한다. `--check`는 원장 재현 여부를 확인하며 그 자체로 법률 승인하지 않는다. 미국·일본 및 연령 진행률 갱신 도구는 전체 원장의 최신 승인 건수를 유지한다.
