- 호주 462: LIN25/014 6(c)(ii)(B)의 명시적 사후시험 증거 경로와 법령·안내문 우선순위를 보존했다. Berenguel 고등법원 원문 [24]–[26]을 추가로 확인해 시간 제목만으로 사후시험을 일률 배제하지 않도록 했다. 그 사건 자체는 당시885이며462의 직접 판결이라고 주장하지 않는다. 증거 적격성을 개별462 자동 적격으로 변환하지 않는다.
- 독일 공제: 독문 je(각)·jeweils mit Zahlungsnachweis(각 지급증명)와 한국어 1,000유로씩 감액을 대조했다. 3,500−1,000×n은 각각의 증빙이 실제 인정되는 조건 아래의 문언·산술 해석이다. n=0/1/2에 따라3,500/2,500/1,500유로다. 별도 기관 회신 또는 공관이 직접 제시한 숫자 예시라고 주장하지 않는다.

## DB와 팀 공유

DB의 원본 policy_text와 출처 연결은 보존하며, 최신 검토 문구는 별도 버전 및 policy_reviewed_for_development 조회 뷰로 제공한다. 팀원은 해당 뷰 또는 묶음의 reviewed_policies SQLite 테이블을 사용한다. 사용자 답변·개인 자격 판정·임베딩 서비스 플래그는 이번 작업에서 개방하지 않는다.

공유 파일은 data/exports/team_review_20261028.zip이다. SQLite, 네 테이블 JSON, 전체590개 판정, 승인570개 문구와 근거 파일, SHA256 목록, 독립 검증기를 포함한다. DB 계정·.env·임베딩은 포함하지 않는다. 압축을 풀고 python verify_bundle.py로 검증하며 DB 계정 없이 사용할 수 있다.

DB 반영·백업은 db_review_update_20261028.json, ZIP 해시·건수·실제 압축 해제 검증 결과는 team_export_receipt_20261028.json에 있다. 이 보고서 이후의 코드 재현은 finalize_last_two_rules.py, finalize_global_policy_wording.py, audit_policy_content_approvals.py, apply_policy_review_metadata.py, export_team_review_bundle.py 순서다.
